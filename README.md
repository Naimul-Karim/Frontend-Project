# 1. Todo App

A simple and responsive Todo App built with React and Tailwind CSS.

## Project Overview

This project is a Todo application that helps users manage their daily tasks. Users can add, edit, delete, complete, and filter todos. Todo data is stored in Local Storage, so tasks remain available after refreshing the page. The app also includes Light and Dark modes.

## Features

* Add, edit and delete todos
* Mark todos as completed
* Local Storage support
* Dark / Light mode
* Todo progress tracking
* Filter todos
